# Vortex Mobile — releases

Android builds of **Vortex Mobile**: download from any site, YouTube & YouTube Music without ads.

- Download the latest APK from **[Releases](../../releases/latest)**:
  - `Vortex-Mobile-*-arm64.apk` — most phones
  - `Vortex-Mobile-*-armv7.apk` — older phones
- Already installed? The app updates itself: it checks `latest.json` of the latest release once a day
  (Settings → Updates to check now).
