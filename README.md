## Download

Get the latest APK from **[Releases](../../releases/latest)**:

| File | For |
|---|---|
| `Vortex-Mobile-<version>-arm64.apk` | Most phones (64-bit, 2017 and newer) |
| `Vortex-Mobile-<version>-armv7.apk` | Older 32-bit phones |

Not sure? Install **arm64** first — if Android says the app is not compatible, use **armv7**.

## Install

1. Download the APK on your phone.
2. Open it and allow **Install unknown apps** for your browser or file manager when asked.
3. Tap **Install**.

## Updates

Already installed? The app updates itself: it checks `latest.json` of the latest release once a day
(**Settings → Updates** to check now).

## What's in this repository

This repository only hosts the release builds and the update feed:

- Each [release](../../releases) contains the two APKs and `latest.json` (version info read by the in-app updater).
- Tags follow semantic versioning: `vMAJOR.MINOR.PATCH`.
